# V0.1 build notes

- The portable ARM64 Blender executable returned Windows status 0xC0000022 in the managed sandbox. Running the same Blender build outside the sandbox succeeded. No new Blender installation was needed.
- The first independent topology check used trimesh mesh splitting. The system Python had neither of the graph backends that API requires. Manifold's connected-solid decomposition provided the check with the installed dependencies.
- The first previews were grayscale. The final rig links the material shaders explicitly, assigns their slots after the solid operations, and uses lower area-light power.
- The helmet and mask have straight keyed joints. A roof stop and a mask seating face define the assembled pose. The helmet tabs engage 2.5 mm and the mask tabs engage 6 mm. The 0.25 mm per-side gap is a digital baseline. Printer-specific fit and retention remain unmeasured.
