# Project guidance

Keep model-specific assets under `models/<model-id>/` and reusable work under `shared/`. Use millimetres for engineering dimensions; document assumptions and printer-specific tolerances. Prefer reproducible Blender Python scripts and separate watertight meshes. Never claim printability or fit without validation. Keep original references unchanged. Start Titan 02 with the inner frame, helmet shell and face mask. Record experiments and test prints before expanding scope.
